# Developer Technology Trends & Job Market Analysis

An end-to-end data analytics project exploring global software developer choices, demographic distributions, and hiring trends. This project features a multi-tab business intelligence dashboard built using **IBM Cognos Analytics** and a comprehensive strategic insights presentation.

## 📊 Interactive Dashboard Overview
The interactive dashboard is split into three thematic focal areas to track tech movements:

Demonstrates what developer stacks are currently dominating the production market.

### 2. Future Technology Trends

### 3. Demographics & Distribution
Breaks down the global developer community by age metrics, education tiers, and geographical locations.

## 📈 Key Insights & Findings
* **Language Dominance:** Web development stacks lead current market use, with the combination of **HTML/CSS + JavaScript + TypeScript** pulling ahead significantly. C# and Python are projected to see the highest growth in developer interest next year.
* **Database Trends:** **PostgreSQL** clearly rules enterprise data storage, ranking first in both current operational use and future preference (growing roughly 27% in next-year interest).
* **Cloud & Framework Infrastructure:** **AWS** maintains market leadership over Microsoft Azure across both current and future choices. **Spring Boot** and **React** form the foundational pillars for active web frameworks.
* **Community Layout:** The developer landscape leans heavily toward early-to-mid career professionals, with roughly 69% of individuals falling in the 25–44 age bracket, and 45.8% holding a formal Bachelor's Degree.
